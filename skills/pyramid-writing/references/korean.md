# 한국어 문서 규칙

한국어로 문서를 쓸 때 `SKILL.md`의 규칙에 더해 적용하는 표현 규칙과, 각 규칙의 한국어 예시다. 구조 규칙(So What, Why So, MECE)은 `SKILL.md`와 같다.

## 문체

- **1단계 불릿은 명사형으로 끝낸다.** '~중', '~필요', '~미확인', '~결정'처럼 끝낸다.
- **구두 설명체를 쓰지 않는다.** '~습니다', '~인데요', '~하겠습니다'는 불릿에 쓰지 않는다. 문장으로 쓰는 요약 단락과 이메일에서는 간결한 존댓말을 쓴다.
- **구어체 수치 표현을 쓰지 않는다.** '반토막', '폭망' 대신 '급감', '급증'을 쓰고 수치를 붙인다.
- **AI 문체는 `ai-tells.ko.md`로 걷어낸다.** 번역투('~에 대해', '~를 통해', '~를 가지고 있다')가 가장 흔하다.

## 제목

- **제목은 `키워드 : 결론`으로 쓴다.** 앞에는 그 장이 무엇을 다루는지 알려 주는 명사형 키워드를, ` : ` 뒤에는 결론을 둔다.
  - 주제만 : `1. 채널별 비교`
  - 결론만 : `1. 제휴 채널은 전체 이익의 0.7%로 전환율도 가장 낮음`
  - 키워드 : 결론 : `1. 채널별 비교 : 제휴 채널은 전체 이익의 0.7%`
- 키워드는 독자가 찾을 때 쓰는 말로 짧게 쓴다 (`구매 경로`, `계약 검토`).
- 결론은 한 가지만 짧게 쓴다. 나머지는 첫 불릿으로 내린다.
- 소제목도 같은 꼴로 쓴다 : `3-1. 진입 방식 : 목록 검색 후 클릭이 57%`

## 구분 기호

- 줄 중간의 구분은 ` : `로 쓴다. 줄표(—)는 쓰지 않는다.
- 줄 맨 앞의 불릿 기호 `-`는 그대로 쓴다.
  - 줄표 : `1. 정의 — 성과 상위 매장과 여는 1개월 이내 공동 행사`
  - 쌍점 : `1. 정의 : 성과 상위 매장과 여는 1개월 이내 공동 행사`

## 규칙별 예시

| 규칙 | 고치기 전 | 고친 뒤 |
|---|---|---|
| 제목은 `키워드 : 결론` | `3. 재구매율 현황` (주제만), `3. 첫 구매 후 30일 내 이탈로 재구매율 하락` (결론만) | `3. 재구매율 : 하락, 첫 구매 후 30일 내 이탈이 원인` |
| 데이터에서 액션까지 | `재구매 고객의 62%가 알림 수신자` | `재구매 고객의 62%가 알림 수신자 → 첫 구매 직후 알림 동의 유도` |
| 결정 제목에 단서 금지 | `무료 배송 : 유효(단, 장기 효과는 추가 검증 필요)` | `무료 배송 : 유효 판정, 다음 달 전체 확대` |
| 사후관리는 숫자로 | `환불이 많이 늘면 재검토` | `환불 건수가 직전 3개월 평균의 200% 이상(월 90건 초과)이면 재검토` |
| 요약 범위 명시 | `지역별 매출` | `지역별 매출 : 전년 동기 대비, 앱 기준` |
| 미완 항목 | `추후 공유` | `TBD (다음 주 2차 시안 예정)` |
| 해결된 문제는 한 줄 | 배송 지연의 경위 세 문장 | `배송 지연 영향 종료` |
| 약속은 완곡하게 | `내년 추진` | `가능성 검토 후 추진 판단` |

## 불릿 하나에 지표 하나

```
나쁨 : 참여 매장 매출 1.9배 · 주문 1.8배 · 전환율 6.4 → 9.8%

좋음 : 참여 매장
         - 매출 1.9배
         - 주문 1.8배
         - 전환율 6.4 → 9.8%
```

## 전체 예시

**고치기 전**

```
2. 프로모션 결과

지난주 진행한 무료 배송 프로모션은 전반적으로 좋은 성과를 보였습니다.
참여 매장 매출 1.9배 · 주문 1.8배 · 전환율 6.4 → 9.8%로 반토막 났던
지난달 대비 크게 회복했습니다(전월 5.1%). 다만 장기 효과는 아직 확인이
필요하며 재고 문제도 영향을 줬을 수 있습니다.
```

**고친 뒤**

```
2. 프로모션 결과 : 무료 배송 유효 판정, 다음 달 전체 매장 확대

- **참여 매장 매출 1.9배 → 전체 매장으로 확대**
  - 근거 : 프로모션 결과 시트(링크)
  - 매출 1.9배
  - 주문 1.8배
  - 전환율 6.4 → 9.8%
- 사후관리
  - 확대 후 4주 전환율이 8% 미만이면 재검토

비고
- 장기 효과 미확인 : 4주 뒤 재구매율로 재확인
- 재고 부족의 영향은 추정, 데이터 미확보
```

## 섹션 이름

| 영어 | 한국어 |
|---|---|
| Notes, Caveats | 비고, 주의사항 |
| Follow-up | 사후관리 |
| Source | 근거, 출처 |
| evidence needed | 근거 필요 |
| estimate | 추정 |
| no issue | 문제없음 |
